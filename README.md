## About the Project

Most companies use software to scan resumes. This software looks for specific keywords to decide if a candidate fits a role. This process often feels like a barrier. filtrd solves this problem. This application uses artificial intelligence to help you tailor your resume for these systems.

You provide your work history. You provide the job description. The software writes a professional, optimized document that matches the criteria the company expects. It works in English and Spanish. You save time. You increase your chances of reaching a human recruiter.

## 🛠 Using the Application

The interface is simple. You see two main text boxes.

### Step 1: Input your CV
Copy the text from your current resume. Paste it into the left box. Ensure your contact details and previous roles appear clearly. 

### Step 2: Input the Job Description
Find the job posting online. Copy the text of the job description. Paste it into the right box. Include the requirements and responsibilities listed by the employer.

### Step 3: Run the AI
Click the button marked "Generate." The software analyzes the text. It identifies which skills and keywords matter for this specific role. It rewrites your resume sections to align with these needs. 

### Step 4: Review and Export
The window updates with your new resume text. Read the output. Add or remove information as you see fit. Once satisfied, click the "Export PDF" button. This saves a clean, professional file to your desktop ready for submission.

Your personal data stays safe. The application functions as a tool for your local workspace. It sends specific segments of text to the AI engine for processing. It does not store your employment history on a public server. Always review the final PDF before you send it to a potential employer.
